# Logo Assets

Place the following files in this folder:

| Filename        | Size         | Format | Description                                      |
|-----------------|--------------|--------|--------------------------------------------------|
| `logo.png`      | 400 × 200 px | PNG    | **Main logo** — flat, transparent background. Used in navbar and footer. |
| `logo-white.png`| 400 × 200 px | PNG    | White version for dark backgrounds (optional).  |
| `favicon.png`   | 64 × 64 px   | PNG    | Browser tab icon — square crop of logo icon.    |
| `og-image.jpg`  | 1200 × 630 px| JPG    | Social media share image (Open Graph). Use a compelling field photo with logo overlaid. |

## Notes
- The logo you uploaded (3D gold plaque mockup) is beautiful for print and social media.
- For the website navbar, request a **flat, transparent PNG** from the designer.
- The flat logo should use the same gold (#C9A84C) and navy (#1A2A4A) color palette.
- Do not use the 3D mockup version as the navbar logo — it will not render cleanly at small sizes.
